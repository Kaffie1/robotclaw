# Examples

## Example 1: Need More Info

输入 QA：

```text
Q: 机器人为什么不动？
A: 先确认急停是不是按下了，再看底盘是否上电，另外把当前报错截图发我。
```

输出：

```json
{
  "type": "qa_message",
  "question": "机器人为什么不动？",
  "answer": "需要先补充急停状态、底盘上电状态和当前报错信息，才能继续判断。",
  "steps": [],
  "conclusion": "",
  "follow_up_questions": [
    "请确认机器人急停当前是否处于按下状态。",
    "请确认底盘当前是否已经上电。",
    "请提供当前报错截图或报错原文。"
  ]
}
```

## Example 2: Concluded Answer

输入 QA：

```text
Q: 地图加载失败怎么处理？
A: 这次不是地图文件损坏，而是挂载目录没准备好。我们检查后发现配置里的地图路径不存在，所以加载直接失败。补齐目录并重新加载后恢复正常。
```

输出：

```json
{
  "type": "qa_message",
  "question": "地图加载失败怎么处理？",
  "answer": "这次地图加载失败不是地图文件损坏，而是挂载目录未准备好，导致配置中的地图路径不存在。",
  "steps": [
    "检查地图文件是否损坏。",
    "确认配置中的地图路径是否存在。",
    "发现实际问题是挂载目录未准备好，导致路径不存在。",
    "补齐目录并重新加载后恢复正常。"
  ],
  "conclusion": "本次故障由地图挂载目录缺失引起，不是地图文件损坏。",
  "follow_up_questions": []
}
```
