使用说明

按“连接 -> 选择部署方式 -> 查看后台任务 -> 导出日志”的顺序操作最稳妥

这里把现场最常用的流程、自动部署入口和异常处理建议整理到一起，尽量做到照着页面就能操作。

OPS GUIDE

STANDARD FLOW

推荐操作流程

  1. 先在“远程连接”页填写设备信息并点击“连接机器人”

    至少需要填写 ORIN 的主机、端口、用户名和密码。若后续要执行 PICO 相关部署或导出 PICO 日志，请同时补全 PICO 的主机、端口、用户名和密码。

  2. 确认页面右上角状态变为“已连接”

    连接成功后，页面右上角会显示“已连接”。同时这组 ORIN / PICO 参数会自动写入“已缓存连接”，后续可以直接从下拉里选择复用。

  3. 进入“部署”页，按实际场景选择部署方式

    整包部署用于 firmware 升级；模块部署用于替换单个模块 deb。如果页面里已经配置了自动部署版本，优先从“自动部署版本”下拉中选择；如果包已经放在文件服务器上，也可以直接填写“文件服务器包路径”，不必本地上传。

  4. 按页面要求选择文件或填写服务器路径，然后创建任务

    整包部署选择 firmware 文件；模块部署选择对应模块并上传 deb。若选择了自动部署版本，页面会自动带出包路径并跳过本地上传。确认信息无误后点击对应按钮，任务会进入后台执行。

  5. 整包部署上传后先选机型，再点击“继续部署”

    整包 firmware 上传完成后，系统会先识别可选机型，并尝试读取远端 `ROBOT_TYPE`。你需要确认机型下拉框里的值是否正确，然后点击“继续部署”；如果没有做这一步，流程会停在等待继续的状态。若选择的是自动部署版本，点击一次“继续部署”后，系统会按顺序把当前版本下的整包依次执行完。

  6. 在“后台任务”中持续查看状态、结果和执行日志

    任务会依次显示等待中、执行中、成功、成功但有告警或失败。点击任务后可以查看完整后台日志；如需把结果发给他人排查，可以直接使用“复制日志”。模块自动部署会先批量替换文件，再统一执行部署。

  7. 部署异常时进入“日志”页导出 ORIN / PICO 日志

    ORIN 日志支持按模块和时间范围筛选，PICO 日志支持按时间范围导出。建议在部署失败、服务未拉起、功能异常时立刻导出，并把后台任务日志和压缩包一起保存，避免日志被后续操作覆盖。

BEFORE YOU START

开始前检查

  • 确认机器人与当前电脑网络互通，主机、端口、用户名、密码填写正确，避免在部署时才发现连接失败。
  • 整包部署优先准备 `.firmware` 文件；模块部署准备目标模块对应的 `.deb` 文件；如果使用自动部署版本，先确认版本下拉中已经有正确的版本配置。
  • 如果安装包已经放在文件服务器上，可以直接填写“文件服务器包路径”，这样可以跳过本地文件选择和浏览器上传；路径为空时才会使用本地上传文件。
  • 模块部署前确认模块名选择正确；`COMPOSE_PROFILES` 会由系统从机器人宿主机自动读取，不需要手动填写。
  • 如果要部署 PICO 或导出 PICO 日志，请在连接 ORIN 的同时补全 PICO 的主机、端口、用户名和密码；PICO 相关操作依赖 ORIN 跳板。

DEPLOY MODES

两种部署方式说明

整包部署

适合整机升级或现场整包覆盖。第一步是上传 firmware 或读取服务器包路径，第二步是确认机型并点击“继续部署”。如果选择了自动部署版本，系统会在你确认机型后按顺序完成当前版本下的整包部署。

模块部署

适合替换单个模块。选择模块名并上传对应的 deb 后，系统会清理该模块目录下同前缀的旧包，再执行容器重启相关操作；如果使用自动部署版本，同一模块下配置的多个包会先批量替换，再统一执行部署。

LOG EXPORT

日志下载流程说明

  1. 先确认设备已经连接成功

    日志导出依赖当前 SSH 连接。进入“日志”页前，先确认右上角状态为“已连接”；如果要导出 PICO 日志，也请确保 PICO 连接信息已经填写完整。

  2. 进入“日志”页，选择 ORIN 或 PICO 日志导出

    ORIN 和 PICO 分成两块独立区域。ORIN 日志适合按模块筛选后导出；PICO 日志按时间范围直接导出即可。

  3. 导出 ORIN 日志时先确认模块筛选和时间范围

    ORIN 默认全选模块。你可以按现场需要只保留目标模块，再选择开始时间和结束时间，然后点击“导出 ORIN 日志”。时间范围越大，导出的压缩包通常越大；如果问题只发生在某个模块，建议缩小模块范围后再导出。

  4. 导出 PICO 日志时重点确认时间范围

    PICO 日志不区分模块，直接按照开始时间和结束时间导出。建议把时间范围控制在问题发生前后，避免下载过多无关日志；若导出失败，优先回到“远程连接”确认 PICO 参数是否填写完整。

  5. 导出失败时先检查时间范围、连接状态和目标设备

    如果点击导出后没有结果或提示失败，优先确认当前连接是否还在线、时间范围是否合理、以及 ORIN / PICO 是否选对。必要时先回到“远程连接”重新连接，再重新导出；导出成功后浏览器会开始下载压缩包，可结合后台任务时间点一起留档。

TROUBLESHOOTING

常见问题处理

连接失败

优先检查 IP、端口、账号密码和网络连通性；如果 ORIN 能连但 PICO 不能连，可以先完成 ORIN 相关部署，PICO 相关任务等网络恢复后再处理。若使用了缓存连接，也建议重新核对是否还是当前设备。

上传后无法继续

整包部署必须在识别机型后手动选择机型并点击“继续部署”；如果下拉没有机型选项，先查看任务日志，确认 firmware 包是否有效、识别命令是否执行成功，以及是否已经错误地填写了文件服务器路径或自动部署版本。

部署失败

先在“后台任务”里复制执行日志，再去“日志”页按时间范围导出 ORIN / PICO 日志。定位时优先关注安装命令、容器重启、健康检查、远程路径是否正确，以及是否出现“成功但有告警”的情况。
