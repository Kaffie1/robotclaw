# 移动感知升级手册（用户版）

# 文档说明

本文档用于指导用户完成以下三种升级操作，并说明每种方式适用的场景：

1. 使用项目升级控制台对 `run 升级包`进行单独模块升级

2. 使用项目升级控制台进行`整包`升级

3. 使用项目升级控制台进行`单独模块deb包`替换

注：用户按照适用场景选择对应的升级方式。第2章为场景与升级方式的映射说明，3\-5章为各个方式的具体操作。

操作顺序说明：

- 通过场景选择对应的的方式

- 跳转到方式对应的章节，按照步骤进行部署

- 所有的失败均找研发来处理

# 升级方式使用场景

|**方式**|**说明**|**适用场景**|
|---|---|---|
|\.run 单模块升级|用户拿到一个可执行的 \.run 升级包，通过升级控制台上传整机安装包或填写文件服务器路径，执行单模块升级|1. 需要升级移动版本<br>2. 需要升级移动模块下的子模块|
|项目整包升级|通过升级控制台上传整机安装包或填写文件服务器路径，执行整项目升级|1. 首次部署<br>2. 项目交付的最终部署|
|项目模块包替换|通过升级控制台上传某个模块的 deb 包，替换项目中的单独模块并重启该模块|1. 模块同版本调试，只需要进行定位等单模块的ros调试或者算法调试|

# 方式一：使用 `.run` 升级

## 操作步骤

1. 启动升级控制台服务

2. 浏览器访问 `http://<机器人ip>:8767`（若访问不了，先按照第6章部署升级控制网页）

3. 进入首页的 `ROS1部署/单模块部署` 区域

4. 选择部署目标（见 7\.1 获取run包）

5. 上传整包安装文件，或者填写文件服务器路径（keep config 为是否保留原来的配置）

6. 选择需要升级的模块（all：升级整个移动模块，其余为升级指定的模块）

7. 点击创建单模块部署任务，等待系统执行安装

8. 在 `后台任务` 页面查看执行进度和日志
## 注意事项

- 如果进入“机型选择”，说明安装包机型识别已完成，但仍需要人工确认机型

- 使用文件服务器路径时，前提是后端机器可以访问该文件服务器（仅内网用户可以使用）

- 升级后原来的config文件都会被覆盖，请先保存备份

# 方式二：整包升级

## 操作步骤

1. 启动升级控制台服务

2. 浏览器访问 `http://<机器人ip>:8767`（若访问不了，先按照第6章部署升级控制网页）

3. 进入首页的 `ROS1部署/整包部署` 区域

4. 选择部署目标（见 7\.2 获取整包）

5. 上传整包安装文件，或者填写文件服务器路径

6. 点击创建整包部署任务，等待机型选择

7. 选完机型后点击继续部署，等待任务完成

8. 在 `后台任务` 页面查看执行进度和日志
## 整包部署的目标说明

- `ORIN`：默认在当前部署机本地执行

- `PICO`：在PICO上部署

## 注意事项

- 如果进入“等待确认”，说明安装包机型识别已完成，但仍需要人工确认机型

- 使用文件服务器路径时，前提是后端机器可以访问该文件服务器（仅内网用户可以使用）

- 升级后原来的config文件都会被覆盖，请先保存备份

# 方式三：单独模块包替换

## 当前支持的模块

- `chassis`：底盘模块

- `perception`：包含建图、定位、感知模块

- `sensor_lidar`：激光传感器模块

- `navigation`：导航模块

- `map_server`：地图管理模块

## 操作步骤

1. 启动升级控制台服务

2. 浏览器访问 `http://<机器人ip>:8767`（若访问不了，先按照第6章部署升级控制网页）

3. 进入首页的 `ROS1部署/单包部署` 区域

4. 在下拉框中选择要替换的模块

5. 上传该模块对应的 `deb` 包（由研发给出），或者填写文件服务器路径（仅内网用户可以使用）

6. 点击创建单包部署任务，等待任务完成
# 升级控制台安装方式

## 准备安装包

发送给用户的安装包例如：

- `zj-humanoid-robot-web_1.0.0-0jammy_arm64.deb`

以下步骤以 `zj-humanoid-robot-web_1.0.0-0jammy_arm64.deb` 为例。

deb包地址：http://10\.51\.33\.211:10000/\#/modules/tool/robot\-web/release（仅内网用户使用，取最新）

## 完整示例

```Bash
scp ./zj-humanoid-robot-web_1.0.0-0jammy_arm64.deb naviai@192.168.1.100:/tmp/
ssh naviai@192.168.1.100
cd /tmp
sudo dpkg -i zj-humanoid-robot-web_1.0.0-0jammy_arm64.deb
sudo systemctl status robot-web.service
```

## 其他命令

```Bash
# 默认是开机自启，无需操作

# 启动
sudo systemctl start robot-web.service
# 停止
sudo systemctl stop robot-web.service
# 重启
sudo systemctl restart robot-web.service
#查看状态
sudo systemctl status robot-web.service
# 查看实时日志
sudo journalctl -u robot-web.service -f

# 开启开机自启
sudo systemctl enable robot-web.service
# 关闭开机自启
sudo systemctl disable robot-web.service
# 查询是否开机自启
systemctl is-enabled robot-web.service
```

# 升级包获取

## `.run` 包获取

用户会收到一个`.run`包。

来源如下两种：

- 研发直接给出`.run`包

- 去文件服务器中获取。run包地址：http://10\.51\.33\.211:10000/\#/modules/tool/nav\_upgrade/release（仅内网用户使用，按版本取），根据版本进行选择。

## 整包获取

用户会收到一个`Middleware`包。

来源如下两种：

- 研发直接给出`Middleware`包

- 去文件服务器中获取。run包地址：http://10\.51\.33\.211:10000/\#/modules/Middleware/release（仅内网用户使用，按版本取）
