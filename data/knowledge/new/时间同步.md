# 具体步骤

- 检查/home/naviai/navi\_project/containers/shared/time\_sync目录下有没有set\_autostart\.sh（自起脚本） 和 time\_sync\.sh（时间同步脚本），若没有先创建目录然后把文件放进去。

- 检查是否存在/etc/systemd/system/time\-sync\.service。

- 若不存在就执行上述的脚本（注：只需要执行一次即可，需要在有外网的情况下执行）

```Bash
cd /home/naviai/navi_project/containers/shared/time_sync
chmod +x *.sh
sudo time_sync.sh
# 等待成功
sudo set_autostart.sh
```

- 验证是否同步

    - 输入**chronyc tracking**，查看 Reference ID  和 Last offset，如果ID为 192\.168\.217\.1 且 Last offset 小于10ms就说明同步成功。

    Skew            : 77.008 ppm
