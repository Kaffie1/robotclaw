# **概述**

## 文档目的

本文档旨在向客户可以快速上手导航、建图等功能

## 适用范围

- 操作系统：Ubuntu 20.04、2204
- ROS版本：ROS1 Noetic
- 支持语言：Python3.x，C++17及以上

# 机器人连接

- **硬件连接**
  - 准备：带 DP 口的数据线、显示屏、键鼠套装
  - 连接规则：
    - DP 线：一端插入机器人 "大脑"（主控模块），另一端接显示屏
    - 键鼠：USB 接口插入机器人（DP 口左侧）
  - 若没有DP口则询问平台组rustdesk的使用方法
- **系统登录与网络配置**
  - 启动机器人后，显示屏显示登录界面，密码：`naviai@2024`
  - 登录桌面后，连接目标 WiFi（需与操作 PC 在**同一局域网**）
- **连接方式选择**
  - 方式 1（推荐）：PC 通过 SSH 连接机器人（需知道机器人 IP，可在机器人桌面通过`ifconfig`或网络设置查询）
  - 方式 2：直接在机器人本体桌面操作（无需 SSH）

## 定位流程

- 检查激光数据

```Python
# 进入 rosbridge 容器
cd ~/navi_project
docker compose exec -it rosbridge bash
rostopic echo /livox/lidar | grep point_num

# 如果数值在 20000 左右说明正常，若没有值或者明显小于 20000,执行如下指令
# 新建终端
cd ~/navi_project
docker compose down sensor_lidar
docker compose up -d sensor_lidar
```

- 查看可用地图并进行定位

```Python
# 还是在 rosbridge 容器下
rosservice call /zj_humanoid/navigation/get_map_list

# 返回
code: 0
message: "\u64CD\u4F5C\u6210\u529F"
map_name_list: 
  - D_floor

# 选择返回列表中的其中一张地图名，以D_floor举例进行设置地图（用于导航）和定位
rosservice call /zj_humanoid/navigation/set_map "map_name: 'D_floor'" 
rosservice call /zj_humanoid/perception/reloc "{method: 'auto', map_path: 'D_floor', x_pos: 0.0, y_pos: 0.0, z_pos: 0.0, x_ori: 0.0, y_ori: 0.0,
  z_ori: 0.0, w_ori: 0.0}" 
  
 # 成功后 rviz 上会显示出定位点
```

# 建图流程

## 话题概览

| **接口名**               | **图示命名**     | **类型**  | **执行频率** | **ROS话题名**                        | **消息类型**                              |
| :----------------------- | :--------------- | :-------- | :----------- | :----------------------------------- | :---------------------------------------- |
| 开始建图服务             | start mapping    | service   | --           | /perception/mapping_service          | naviai_localization_msgs::Mapping         |
| 建图反馈发布接口（全量） | mapping feedback | topic/pub | 1hz          | /projected_map                       | nav_msgs/OccupancyGrid                    |
| 结束建图服务             | end mapping      | service   | --           | /perception/post_processing          | naviai_localization_msgs::Post_processing |
| 建图结果发布接口         | mapping result   | topic/pub | 1hz          | /perception/mapping_result           | naviai_localization_msgs::MappingResult   |
| 获取可用地图列表服务     | get maplist      | service   | --           | /zj_humanoid/navigation/get_map_list | map_server_msgs::GetMapList               |

##  建图流程

- 检查激光数据

```Python
# 进入 rosbridge 容器
cd ~/navi_project
docker compose exec -it rosbridge bash
rostopic echo /livox/lidar | grep point_num

# 如果数值在 20000 左右说明正常，若没有值或者明显小于 20000,执行如下指令
# 新建终端
cd ~/navi_project
docker compose down sensor_lidar
docker compose up -d sensor_lidar
```

- 开启建图

```Python
# 还在 rosbridge 容器
rosservice call /perception/mapping_service "{map_name: 'D_floor', z_floor: 0.1, z_ceil: 2.0, resolution: 0.05, scene: 0}" 
```

- 控制机器人走遍地图
  - 需要多走几个圈，即让机器人多次回到之前走过的问题
  - 保证机器人走遍地图
- 结束建图

```Python
rosservice call /perception/post_processing "method: 0" 
# 该过程需要 2-5 min左右
```

- 查看地图

```Python
rosservice call /zj_humanoid/navigation/get_map_list

# 返回
code: 0
message: "\u64CD\u4F5C\u6210\u529F"
map_name_list: 
  - D_floor

# 若返回中存在刚才的地图名说明建图成功
```
